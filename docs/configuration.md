# Configuration

Set up Wi-Fi and Navidrome from a Windows PC with the [USB setup guide](setup.md). The public firmware has no baked-in SSID, server URL, account, certificate or ADB host key. Configuration is stored in private app data after import; the temporary USB-visible file is deleted by the app.

The configured SSID is the home network used for online streaming and downloads. On any other network the player stays in offline mode. Device preferences, cache policy and playback options are available through Settings on the Y1.
