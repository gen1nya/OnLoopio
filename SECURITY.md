# Security policy

Please report suspected credential exposure, unsafe image installation, or authentication bypass privately through [GitHub's vulnerability reporting for this repository](https://github.com/smbdsbrain/OnLoopio/security/advisories/new). Do not put secrets or personal device dumps in a public issue.

The supported release line is 0.9.x for the verified Innioasis Y1 Type A profile. A report should include the version, reproduction steps and impact, with secrets redacted. We will investigate and coordinate a fix before public disclosure.
